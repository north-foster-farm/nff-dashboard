One-time setup so Jim can submit from his own phone (free)

This uses your Supabase. Paste your project URL and anon key into the CONFIG block near the top of this file's script, then run this once in the Supabase SQL editor:

create table if not exists nff_pricing (
  person text primary key,
  packs jsonb,
  updated_at timestamptz default now()
);
alter table nff_pricing disable row level security;

Then send Jim his link: your-url.html?me=jim — he sees only a form and a Submit button. You open the plain URL and watch both fill in under Joined view.

Notes on privacy & hosting

The anon key sits in this file, so anyone with the page URL could read/write this one table — keep the hosted link between you and Jim, and don't reuse a project with sensitive data (or add a row-level policy instead of disabling RLS). Host the single file free on Netlify Drop or GitHub Pages. Until you add the keys, the page runs in single-device mode and you can enter both sets of prices yourself.
