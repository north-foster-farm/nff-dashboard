# Scope Workshop — worked examples

Two runs of the method, showing both seed styles described in the playbook.

## `schedule/` — the full chain (story-set seed, playbook §13)

A large, novel feature seeded by a **reviewed user-story set** rather than a
raw requirements dump. Read in order:

1. `1-verbatim-requirements.md` — the raw, unedited brain-dump that triggered
   the workshop (the input fed verbatim to every agent).
2. `2-story-set.md` — the user + boundary stories ("what it is" / "what it is
   not"), walked story-by-story with the owner before the workshop.
3. `3-workshop-brief.md` — the lean brief that packages the shared context +
   source list + open questions for the agents.
4. `4-synthesis.md` — the orchestrator's synthesis: each lens's contribution,
   the disagreement **decision table**, the unified pitch, risks, open
   questions, and the reserve-lens (Dad) commentary.
5. `5-scope-document.md` — the binding **Scope Document** the workshop
   produces. *This is also the input to the Design Bracket* (see
   `../../../design-bracket/examples/schedule/0-scope-document.md`).

## `farm-map/` — the lighter, brief-seed variant

- `workshop-brief.md` — the brief-style seed (the form §13.6 cites).
- `workshop-results.md` — the synthesized output.
