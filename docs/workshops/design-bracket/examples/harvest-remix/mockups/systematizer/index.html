One vocabulary, four surfaces.

Ten primitives distilled from the Rethinker arc, promoted once, then repointed everywhere. Dashboard, Chores, Rounds and Schedule below are built from the same numbered components wearing the same chrome — flush panes on the page, Lora headings, Inter eyebrows, one Hole, one NowRule, one count-driven LoadSpine. Toggle the index to see a primitive appear by the same number on more than one surface. The argument is that the app finally reads as one typeface.
