# Design Bracket — worked example

## `schedule/` — the canonical run (playbook §15)

The Schedule feature: a dense, multi-surface, phone-and-desktop feature where
the interaction model is the whole ballgame — the case the playbook is built
around. Read in order:

0. `0-scope-document.md` — the **binding input**. This is the Scope
   Workshop's output handed in as settled scope (same file as
   `../../../scope-workshop/examples/schedule/5-scope-document.md`). The
   Bracket designs the surface, not this model.
1. `1-design-brief.md` — the design brief: binding scope digest + hero
   screens + the states-to-design list + design-system pointers + device
   tiers + real content.
2. `2-round1-wireframes.md` — Round 1, the wireframe-off: four stances
   (Convention-follower / Flow-first / Minimalist / Rethinker) each produce
   low-fi structural wireframes of every hero screen and its hard states.
3. `3-round2-brief.md` — the **gate** decision written up: which directions
   advance (Minimalist + Rethinker), the grafts carried in, and the must-fix
   notes. Binding for Round 2.
4. `4-the-design.md` — the final **Design**: the winning direction
   (Minimalist, chosen decisively by the Dad reserve lens) + the decision
   spec + the named grafts pulled from the runners-up.

### `mockups/` — the Round 2 coded hi-fi finalists

Open these in a browser side by side — they are self-contained HTML.

- `minimalist-WINNER.html` — the winning mockup (the single-open accordion
  spine), carrying the one load-silhouette graft from Rethinker.
- `rethinker.html` — the runner-up (the load-silhouette spine). Kept so the
  head-to-head the gate set up is visible.

The economic logic of the funnel: four stances were wireframed cheaply in
Round 1, only two were built as coded mockups in Round 2, one shipped.
