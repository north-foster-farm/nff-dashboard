Calendar — chore-block + event rail options

Three ways to render chore-block windows alongside events on the Schedule page's Day/Week view. Same content for all three: Morning chores 6–8 AM, Saturday market 8 AM–1 PM (overlaps morning chore end), Afternoon chores 1–3 PM, Evening chores 5–7 PM. Conflict surfaces visually in different ways. Mobile compromises listed under each.

A · Split sub-columns

Each day column splits in two: chores left, events right. Both sit on the same time axis. Overlap is visible by horizontal proximity at the same Y position.

C · Banded background

Day column stays full-width. Chore-block windows render as faint amber bands behind the time grid. Events sit on top of the bands. Overlap shows as event-on-band visually.
