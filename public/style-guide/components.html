Components

The bounded component library.

One canonical component per job, each with a finite set of variants. Build from these. Where a component is Converging or Proposed, the entry says what ships today versus the target — build toward the target. Live examples render from the real tokens; flip the theme to check both.

Load & week

LoadSpine Stable

The day-load silhouette — one bar per block, interleaved with the day's project gaps, reading farmLoad.spine directly. Color is by kind, not a load-state ramp (slice D, F23/F26): a chore bar is --c-chore (teal, height = item count); a man-down hole keeps the chore color and carries a small conflict triangle (F23 — a symbol, not a hatch/fill); a project bar is --c-project (slate, height = block duration), solid when planned and a blue cross-hatch (HATCH_UNPLANNED, the F11/F26 shared util) when unplanned. No per-bar item counts (F23); the optional summary read sits beside the spine. Bars clamp to the track + overflow-hidden (B2). Kept separate from the Rounds progress bar. Now in ui.jsx.

WarmingBadge Converging

The binary warn/due signal (slice D, F24/F25) that replaced the old continuous should-heat gradient. A Lucide ClockAlert, reading a farmLoad.warming bucket { warn:[…], due:[…] }: any due-today chore → red (--c-cat-processing, the deadline red); else warn amber (--c-warn). ×N when more than one chore is warm; the hover names each chore + when it's due. Inline — no background fill or padding, just the colored glyph, so it reads as part of the line it's on: the day-load summary (after a "·"), the affected DayRailSpine row, and the week pane (per warming day, count hidden).

WeekStrip Stable

The week drawn once off farmLoad.week, desktop sidebar only (the phone layout="header" variant + its should-heat tick were deleted in slice D, NO-LEGACY). A row per day · inline mini-spine · identity symbols (F15–F17): the per-day number + heat box are dropped for a teal Moon when an overnight chore touches the day (overnightByISO, both days a night spans), a periwinkle E KindBadge when the day has an event, a warn/due WarmingBadge (ClockAlert) when it has a warming chore (warmingByISO), and an amber conflict triangle when it has man-down conflicts (each hovers to its detail, fed by conflictsByISO). The symbol cell is a fixed width, left-aligned, so spines stay equal-width and badges align in a column. Bars scaled to week.max, clamped + overflow-hidden (B1). Now in ui.jsx; Step 3 deleted the center WeekSpines + the sidebar WeekList it folds in.
